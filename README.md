# 📊 50:50 策略歷史回測與自動偵測系統 (Rebalance Backtest)

這是一個基於 Python 與 Pandas 開發的自動化投資組合再平衡回測工具。系統可自動讀取線上 Google Sheets / Excel 資料，進行數據清洗，並計算 50:50 策略下的歷史再平衡觸發次數。

---

## 🌟 主要功能

- ☁️ **雲端資料同步**：透過 URL 自動讀取最新的 Google Sheet CSV 歷史數據。
- 🧹 **自動數據清洗**：精準濾除表頭雜訊、清洗日期格式並建立時間序列索引。
- 📈 **策略歷史回測**：自動追蹤與統計 `50:50` 策略觸發「再平衡」的總次數。
- 📊 **狀態檢查與視覺化**：呈現詳細的回測區間，並支援回測結果繪圖輸出。
